For this task I built a small portfolio web page and optimized its front-end performance. I created two versions: a "before" page that deliberately contains common problems, and an "after" page where I fixed them. The original page used four very large PNG images of around 8 MB each, loaded two JavaScript files synchronously in the head (one blocking the main thread for about 350 ms), served unminified CSS and JavaScript, and contained unused CSS rules. I measured the baseline with Google PageSpeed Insights and Chrome Lighthouse, recording Performance score, First Contentful Paint, Largest Contentful Paint, Total Blocking Time and Cumulative Layout Shift.

To improve it, I resized the images and converted them to WebP with responsive srcset and sizes attributes, which reduced total page weight from roughly 32 MB to about 30 KB for the initial load. I added lazy loading to below-the-fold images, set explicit width and height attributes to prevent layout shift, and preloaded the hero image with high fetch priority to improve LCP. I minified CSS and JavaScript, removed unused CSS, moved scripts to defer or async, and added long-lived cache headers for static assets. After re-running Lighthouse, I documented the improvements in a before-and-after table in the report. The report also explains each strategy, the challenges I faced, such as balancing image quality against file size, and the lessons learned. The project files are available on GitHub.
